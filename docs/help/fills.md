# Fills

On the T-8 a fill is just another pattern: **SHIFT + STEP 8** (FILL PTN) picks which pattern is the fill, and **SHIFT + STEP 7** (FILL TRG) plays it once before going back to the main pattern.

- Set **FILL** in the rhythm generator (pattern 16 of the current bank by default) and press **Make fill**. It writes a fill for the pattern you're editing into that slot: the same groove for the first half, then snare and tom hits that get denser, louder and rolled towards the end. **Undo** takes it back.
- Press **Fill** in the Playback card while a pattern plays: the fill plays once, starting at the end of the current loop, then the pattern carries on. The bass keeps playing under it.
- In the pattern grid the fill pattern is outlined in blue.

After **Write to T-8**, pick the fill on the T-8 itself with **SHIFT + STEP 8**: there is no MIDI message for it.
