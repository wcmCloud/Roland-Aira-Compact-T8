## Updates

When the editor starts it asks GitHub, at most once a day, whether a newer version has been released. If there is one, an orange chip such as **v1.0.6 available** appears in the status bar; click it to open the release page. **Check for updates** in the About window (or the macOS app menu) asks right away.

The check is a plain request to GitHub's public "latest release" address: it sends no personal data and no identifiers, only the editor's name and version as the User-Agent. Pre-releases are ignored, and if GitHub can't be reached the startup check stays silent. Turn it off with **Check for updates on startup** in the MIDI settings window.
