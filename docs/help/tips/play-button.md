# Play button
<!-- topic: midi-settings -->
**Through the T-8's sounds:** the editor plays the pattern as notes, so you hear edits straight away. **The T-8's own sequencer:** the editor sends clock and the T-8 plays its stored pattern (SYnC AUTO or USB, rXPc on).

The switches send pattern changes to the T-8 (rXPc) and follow the T-8's (tXPc).
