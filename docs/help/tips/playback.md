# Playback
<!-- topic: getting-started -->
Play, Stop and Pause the current pattern at the BPM on the knob. **Follow clock** makes Play wait for an external MIDI clock on the chosen input instead. **Fill** plays the fill pattern once after this loop; **Select on T-8** switches the T-8 to this pattern.

**Audition** plays steps as you edit them; **Show playing step** outlines the playing step in yellow. What Play does is set in the MIDI settings.
