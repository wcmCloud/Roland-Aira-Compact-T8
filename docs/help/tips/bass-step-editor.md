# Step editor
<!-- topic: bass-editing -->
Click a step's note or number to select it, then click a key on the keyboard to give it that note. With **Next step after a note** on, the selection moves on so you can play a line in key by key.

With **T-8 keys** on, you can play the keys on the T-8 itself instead; the key you hold lights up green. The chevrons move the selection.
