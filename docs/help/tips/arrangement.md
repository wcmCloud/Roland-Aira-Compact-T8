# Arrangement
<!-- topic: song -->
With the Song tab open, click patterns in the pattern grid to add them in order. **Fill bank** in the rhythm or bass generator writes eight variations of the open pattern into the next empty slots. Set each entry's bank, pattern, repeats, name and colour; **FILL** plays a fill pattern once as a bridge into the next entry.

The row buttons play from here, move the entry up or down, duplicate it and remove it.
